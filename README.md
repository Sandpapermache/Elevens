# Elevens
A Elevens game with only a one player mode

Rules:
-The system wiill have the 52 decks ready and deal 9 cards on the table visible to the player
-A player can select two pairs of value number, or a set of 3 face cards from the table
-The system shall validate or not validate if two criteras are met: 
      (1)Two value cards add up to 11
      (2)A single set with only one of each face cards {J,Q,K}
  

That contains four classes (Card,Deck, Table, GameController)


ElevensManager.cs and CardSort.cs(helper) scripts (Unity UI handlers)
